## 2. State Descriptions & Transition Rules

1. **`NO_ACTIVATION_LINK`**: Account profile and membership created, but no active cryptographic activation token has been generated.
2. **`PENDING_ACTIVATION`**: A 32-byte cryptographic activation token has been generated (48-hour TTL). The user has not yet set a password.
3. **`ACTIVATION_EXPIRED`**: The 48-hour activation token has expired without being used. Can be regenerated by Admin.
4. **`ACTIVATION_REVOKED`**: The portal access has been revoked by Admin / Head Coach.
5. **`ACTIVE`**: Fully activated account with password set and verified membership.
6. **`SUSPENDED` / `DEACTIVATED`**: Soft-blocked or deactivated state preserving historical training plans, assessments, and attendance records.

---

## 3. Session Invalidation on Role & Permission Changes
- **Trigger Events:** Role promotion, account suspension, password reset, parent-child relationship removal, organization removal.
- **Enforcement:** Real-time query verification + session cache invalidation ensures changes take effect immediately on next request.
